# Machine Learning Methods

## About the course

The course covers the full machine learning pipeline: from Python basics and data preparation to classical ML algorithms and neural networks.

Topics:

- Python fundamentals and OOP
- Exploratory data analysis and data preprocessing
- Gradient descent
- Classification
- Decision trees and ensemble models
- Clustering and dimensionality reduction
- Convolutional and recurrent neural networks

Variant: **25**

---

### Lab 01 — Python Basics

**Goal:** gain practical programming skills in Python.

**Covered:**

- Numbers and strings
- Lists, tuples, dictionaries
- User-defined functions (arguments, return values)
- Exception handling (`try / except / finally`)
- OOP: classes, inheritance, encapsulation, polymorphism, static and class methods

---

### Lab 02 — Exploratory and Predictive Data Analysis

**Goal:** perform exploratory data analysis (EDA) and data preprocessing.

**Dataset:** [Austin Animal Center Intakes]
